# Thinkly. ✨
> **Master Class XII with AI-powered focus.**

Thinkly is a premium study assistant designed for students. It transforms complex topics into aesthetic, high-yield study flows using high-speed AI inference.

## 🚀 Technical Highlights
- **Engine:** Llama 3.3 70B via Groq LPUs (Sub-second latency).
- **Frontend:** React.js with LaTeX ($K_a$, $\int$, $\Delta H$) rendering via KaTeX.
- **Backend:** Node.js + Express.js.
- **UI/UX:** Minimalist 
Aesthetic designed for high-focus sessions.

## 🛠️ Features
- **Smart Notes:** Structured, Markdown-ready study guides.
- **Active Recall:** AI-generated flashcards with flip-animations.
- **Quick Summary:** 5-point high-yield summaries for last-minute revision.
